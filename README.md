# Gene Mathew Wagas

Personal website of Gene Mathew Wagas, a web developer and IT specialist who helps small businesses grow with websites, web apps, business systems and reliable tech support.

**Live site:** [www.genemat.site](https://www.genemat.site)

## Built with

React, TypeScript, Tailwind CSS and Vite, with a Vercel serverless function for the contact form.

## Running it

```bash
npm install       # install dependencies
npm run dev       # start the development server
npm run build     # type-check, build and prerender for production
npm run preview   # preview the production build
```

## Editing the content

Most of the content lives in [`src/data/portfolioData.ts`](src/data/portfolioData.ts): name, roles, projects, tech stack, services, about text and contact details.

The contact form needs the email settings listed at the top of [`api/contact.js`](api/contact.js).
